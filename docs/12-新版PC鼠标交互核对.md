## 当前实现

| 区域或操作 | 实际行为 |
| --- | --- |
| 桌面 | 自绘铜色噪声底纹与环形刻纹；根据主图重排周边角色框、右下操作武将、底部手牌与四格装备空态；不使用首张草地背景 |
| 角色框 | 使用已采集图集；关羽、曹操使用对应原画，其余现有通用角色保持文字占位；绿框标当前回合，合法目标可点，已选目标红框；体力图标、手牌数和座次独立显示，阵亡灰置并盖章 |
| 指向动画 | 选中牌后悬停合法目标或点选目标，从所选手牌指向角色；金色光晕、亮芯、流动光点和箭头，目标改变时更新；取消即清除。确认出牌及AI公开定向出牌后保留0.8秒并淡出；表现节点穿透鼠标，不提交规则命令 |
| 手牌 | 单行紧凑排列、超量横向滚动、选中抬起、不可用灰置、实际花色点数；等待AI时保留最近操作友军的可见手牌；“整理手牌”按牌名/花色/点数排列，再点恢复原序，不改变实体牌序或当前选择 |
| 弃牌 | 显示应弃与已选数量，点击可多选/取消单张，不允许超选；“一键选择”预选所需数量，选满才能确认。确认时依次提交同一角色的合法Discard命令，取消不消耗牌或随机流 |
| 进度条 | 使用图集红条显示弃牌选择完成比例，属于选择进度；单机响应不限时，不伪装成网络倒计时 |
| 侧栏 | “牌局”显示真实局面和操作提示，“记录”显示完整公开日志，“武将”可点击查看资料；下方保留消息摘要。箭头收起/展开侧栏并重排桌面，操作不推进战斗 |
| 出牌与技能 | 点牌、点目标、确定；自用和响应牌不额外选目标；武圣先点技能再点红牌，奋击先点技能、杀、额外弃牌和目标；取消只清预选 |
| 无懈与拆顺 | 沿用已有合法响应、空询问略过、本次锦囊不再询问；拆顺用居中牌背弹层直接选择；不显示对手暗牌 |
| 保存恢复 | 保存当前规则决策；读档清除未提交选择及指向动画，不重播历史出牌线或伤害；原规则、格式与存档槽位不变 |

界面不增加身份局规则、聊天联网、商城、角色等级、双将及装备效果。已显示的装备栏是空态；通用人物仍为开发占位，不能宣称全部武将美术或正式OL还原通过。只开发鼠标操作，不增加未经参照核实的右键、双击或键盘快捷键。

## 验证与复现

`scripts/check-client.ps1`及`.sh`加入`--battle-desktop-smoke`：真实鼠标切换三栏、收起展开、整理后保留选牌、点目标指向线/鼠标穿透、取消不扣费、五张弃牌预选/反选/禁止超选/一键选择/确认，以及已提交指向动画保留后淡出。原32组布局、2对2与4对4鼠标整局、无懈/拆顺、跨进程恢复及G0入口继续回归。

可通过下列参数生成实际渲染图；程序必须在有图形环境时启动。`discard`和`discard-selected`仅在显式预览入口构造体力1的合成弃牌夹具，不用于普通开局或读档。

```text
--battle-preview <绝对PNG路径> 4 4 target
--battle-preview <绝对PNG路径> 4 4 target-animation
--battle-preview <绝对PNG路径> 2 2 discard
--battle-preview <绝对PNG路径> 2 2 discard-selected
```

`target-animation`额外保存同目录12张`target-frame-00.png`至`target-frame-11.png`供核对光点运动。实际截图不等于完整OL验收；仍需同版本杀闪、无懈、拆顺、技能及濒死画面、配对录像、系统缩放与独立设备检查。
