# 三线故事大纲与制作契约

状态：SG-007初稿，待叙事评审。内容源为`content/planning/story-outline.json`：每条故事15个主线单元，共45个；每线都有仁政、霸业、盟约尾声方向，共9段。尾声方向不另计主线单元，不据此宣布20至30小时内容完成。

本批没有运行时任务、对话执行、城池效果或战斗配置。所有条目保持`status: draft`、`includedInRuntime: false`，不进入客户端资源、不参与抽牌内容哈希，不解除G0及来源冻结关口。

## 1 三套因果

**乡勇：守一乡，护天下。** 从护送伤者、寻找妹妹阿榆出发，求援被推诿后取得首城；旧友何峻主张报复立威，阿榆却带回被裹挟者的经历。中段通过私扣亲属、优先救谁、冒用护乡队名义等事件，把主角推到必须约束自己人的位置。协同剧情要求接受他人复核，接战剧情让后来者获得同等承担责任的资格。末段逐城兑现承诺，由故乡人与外来者共同检验统一后的武力约束。序章护送或追击的选择，在证人与冒名事件中回响。

**寒门学子：求一席，立新序。** 从辨认伪令与救出被牵连者出发，原稿上也有自己的署名；恩主顾衡愿引荐却要求删掉门客责任。求告无门促使主角取得首城，建立公开申辩的案头。中段依次处理恩主例外、两份真文书、引荐门槛和自己的错案，从要求别人听证转为接受自身纠错。协同事件为异议留座，接战事件让后来者承接责任。末段旧恩与功臣同案，保稿或救人的旧选择分别提供材料与证言；统一后最后一次署名要回应对主角本人的质询。

**山野农户：求安身，止流离。** 带失所乡民上路，陶婶要等失散亲人，周禾希望先保住能离开的人。多次借住承诺被撤回后，首城成为不再任人驱逐的选择，随后立即面临后来者是否同样有权留下的问题。中段处理城门外的人、仍在路上的人和返乡分歧；协同剧情承认同住者可以有不同归处，接战剧情让先到与后来者互为接应。末段从守一城转为要求各地分别承担责任。平民去留不造成武将名册流失，统一后仍有返乡、留居与继续接纳的不同归处。

柳平城、阿榆、何峻、顾衡、陈简、陶婶、周禾均为本项目原创候选，不作为历史事实陈述。人物交集只引用现有MVP六人登记；已登记不表示其OL版本、技能和资产已经核验。

| 第二章 | 03 | 各自取得首城的因由、两阶段牌局 |

每线第03、08、11、14、15单元分别标记`first_city`、`dual_general`、`relay_battle`、`unification`、`epilogue`。第08和11约为本线53%和73%的叙事位置，不按支线、游玩时长或名册人数推导。这些是制作索引，尚不会写入游戏功能标记。

统一仍要求24城当前控制、逐城合法卡牌取得记录及终局胜利；对话、同盟或证据不能直接占城。主角可不上场，拒绝可选招募不阻断主线；已招募武将不因叙事冲突被剥夺，敌对立场按人物状态由原部属或原创角色承接。有限状态变体尚待事件制作，不因大纲有一句说明就算完成。

## 3 数据与校验

每单元必填稳定ID、标题、章节、时间阶段、目标、阻碍、关键选择、后果、后继、里程碑及人物交集。无交集显式填空数组，普通单元的里程碑与末单元后继显式填`null`。人物交集含`generalId`和作用`role`，不表示招募或出战前置。

运行`./scripts/check.sh`或`./scripts/dotnet.sh run --project tools/Sanguo.ContentValidator -- content`。编辑器Schema为`content/schemas/story-outline.schema.json`，检查器使用对应C#类型及语义检查：

- 拒绝未知字段、重复JSON属性、缺失字段和空叙事文本。
- 检查三种固定出身、每线15单元、章节0至5的覆盖与顺序、全局ID唯一。
- 主干按数组顺序逐单元连接，只有末单元结束；拒绝断链、跨线、跳步与回环。局部选择留在单元内细化，`nextId`不是运行时路由。
- 时间阶段不可倒退，赵云和吕布不能进入`opening_184`人物交集。
- 里程碑必须唯一且处于对应阶段，每线都须提供三类结局取向。
- 人物引用必须在实际来源登记中存在，并注明对主角事件的作用；同人可跨单元参与，不设重点人物配额。

程序不判断故事质量、选择平衡、时地史实，也不分析自由文本是否暗含招募门槛、强制离队或直接占城。它不验证战斗、剧情可达性、45至90分钟首城体验及人物变体。具体年份、地点、OL完整技能和资产仍需分别评审。
