# 首城事件数据契约

日期：2026-11-17。所属：SG-008内容生产入口。已完成现有首城开发事件的数据化，不关闭SG-008或M2。

## 内容入口

`content/campaigns/first-city.json`是九个运行事件、十八个选项与六段结语的唯一文本来源。它独立于制作草稿`content/planning/story-outline.json`；大纲不直接执行。编辑用结构见`content/schemas/first-city.schema.json`，跨条目唯一性和路线关联以C#校验器为准。

`Sanguo.CampaignCore.csproj`将JSON嵌入程序集。`FirstCityContent`在首次访问首城目录时严格解析，生成不可变数据，`FirstCityStory`按出身和阶段查找；客户端、模拟器和恢复重放使用同一目录。发布程序无需读取外部源JSON，也不依赖启动时的工作目录。修改源文件后须重新编译，运行中不热更新事件。

## 字段与约束

| 字段 | 当前开发契约 |
| --- | --- |
| `formatVersion` | `1`，其他格式拒绝 |
| `packageId` | `campaign.first-city-development.v1` |
| `scope`、`status` | `first-city-development`、`development`；不能改标记冒充正式验收 |
| `cityId` | `city.liuping`；此字段不提供直接占城权限 |
| `routes[].origin` | `damage`、`control`、`tank`各一条，不能重复或缺失 |
| `events[].stage` | 每线0、1、2各一个；阶段3的内城挑战沿用阶段2的选择 |
| `events[].id` | `first-city.{origin}.{01至03}`，必须与所属路线及阶段一致，全部事件ID唯一 |
| `events[].outlineBeatId` | `story.{origin}.{01至03}`，必须与本事件对应且在制作大纲实际存在 |
| `events[].title`、`text` | 标题、正文，均须包含非空白文本 |
| `events[].choices` | 固定`a`、`b`各一个；`text`和`consequence`均不能为空 |
| `epilogues[]` | `openingChoiceId`固定`a`、`b`各一个，`text`不能为空；根据序章选择显示本线结语 |

JSON重复属性、未知属性、缺少必填字段、null集合或条目均拒绝。错误包含文件、字段路径及稳定错误码，例如：`campaigns/first-city.json:$.routes[0].events[0].outlineBeatId [reference.missing]`。

事件数组按`stage`查找，路线按`origin`查找，结语按序章选择查找；数组位置不能改写所属阶段。选项数组决定按钮显示顺序，ID决定提交内容。

## 权限与存档

数据只描述既有叙事和选择；没有任意C#、脚本、命令名或奖励表达式。招募、编队、失败重试、四场遭遇和两阶段攻城仍由`FirstCitySession`与`FirstCityScenario`控制。终局胜利是推进和最终占城的唯一依据；重复结算及伪造战果仍被原事务入口拒绝。

本次逐字迁移保留所有事件ID、选项ID、文本和结语。`FirstCityScenario.ContentHash`仍为`fb530fbecc2c6e6aa65d62e12251b764084dd6da0eafb9e92e638afd12accbe4`，首城格式1与引擎版本不变；已有开发档可继续读取。G0与基础战斗内容摘要不变。

摘要继续覆盖运行时事件、选项后果和实际结语，不按JSON空白或属性排列计算。`outlineBeatId`属于制作溯源且固定对应阶段，不执行大纲内容。后续改写正文、选项、后果或结语会改变战役内容摘要，旧开发档按原合同拒绝；正式迁移尚未实现，不能通过改摘要绕过恢复检查。

## 编辑与验证

1. 编辑运行JSON，保留既有ID和阶段合同；仅调整制作大纲不会自动改变游戏文本。
2. 在Windows运行`pwsh -NoProfile -File scripts/check.ps1`。内容工具复用运行解析器，另核对大纲引用；普通检查通过不表示OL来源冻结或剧情质量验收通过。
3. 构建客户端后执行`--campaign-smoke <专用绝对目录>`，或打开“首城行程”实际查看三线选项和结语。源文件必须经重编译才进入程序。

任务条件、地点步骤、五共享支线、六基础遭遇、正式OL人物招募及完整三种I阶仍需继续制作，当前数据格式不代替通用任务系统。
