# 三国行纪 开发进度

更新：2026-11-12。当前里程碑：M0/G0进行中。当前交付是工具链与恢复试验，不是P0战斗原型；不据此关闭M0、M1或任何OL规则案例。

## 本批实现

| 层 | 实际范围 |
| --- | --- |
| BattleCore | 固定PCG32、可序列化随机状态、有界抽样与洗牌；八张技术牌的抽牌试验 |
| CampaignCore | 固定出身枚举与最小永久名册状态；无任务、招募和领地玩法 |
| Application | 不可变会话、版本和控制者校验、请求ID校验、命令去重及冲突拒绝；单写入锁 |
| Content | 严格JSON字段和类型、格式版本、唯一ID、实体牌花色点数、牌引用；稳定文件排序与SHA-256；三份来源登记的结构、快照一致性、证据引用和本地文件摘要检查；Schema供编辑工具使用，运行时为对应类型与语义校验 |
| Infrastructure | JSON快照信封、SHA-256、引擎规则内容版本检查、临时文件刷新后替换、上一有效备份、损坏档回退；不兼容档拒绝静默覆盖 |
| Godot Client | G0验证场景：抽牌、保存、恢复、新建；中文、键盘焦点与滚动容器；内嵌试验内容，运行无需联网 |
| 工具 | 内容校验器（普通草稿模式与`--require-frozen`严格检查）、会话恢复命令行试验、一键检查脚本；锁定依赖版本 |

核心不引用Godot、文件系统或网络。所有手牌变化来自应用命令；客户端不改变规则状态。抽牌不实现正式回合、杀闪响应、伤害、濒死、武将技能或胜负；试验牌堆耗尽仅结束技术试验。
